# Regenerate v3 Tour Narration Audio

## Overview

The guided tour's narration MP3s are STATIC files in `v3/assets/tour/<stepId>.mp3`,
pre-generated by `v3/tools/gen-tour-audio.mjs`. Editing a `narration` string in
`v3/js/tour/tourSteps.js` does nothing to the audio until the generator is rerun
AND `AUDIO_VERSION` is bumped.

## Writing narration text

- Audio tags like `[tone]` are allowed (consumed by the TTS).
- Pauses: use `…` — NEVER bracketed pause tags, they leak into speech.
- The demo narration deliberately states CWA locations are INDICATIVE
  (to be mapped with Worley) — keep that claim if you edit those steps
  (`grep -in indicative v3/js/tour/tourSteps.js` to find which ones).

## Regeneration workflow

1. Regenerate the touched step(s):

   ```bash
   GEMINI_API_KEY=... node v3/tools/gen-tour-audio.mjs --only <stepId>
   ```

   Omit `--only` to regenerate all steps. The `<stepId>` is the step's `id`
   in tourSteps.js (= the MP3 filename). Model and voice defaults live inside
   the generator; backend selection is automatic — Google AI Studio direct
   when `GEMINI_API_KEY` is set (preferred), else `POST /api/v3/tts`
   (OpenRouter gpt-audio). If `GEMINI_API_KEY` is not in the environment,
   ask Joachim for it — do not skip regeneration.

2. The generator transcribe-verifies each MP3 and retries on tag leaks,
   reporting per-step success/failure in its output. NEVER commit an MP3 whose
   step ended in failure: fix the narration text (usually a bracketed tag or
   odd punctuation), don't force it.

3. Bump `AUDIO_VERSION` in `v3/js/tour/TourEngine.js` (near the top,
   `'v=N'` → `'v=N+1'`) — otherwise browsers keep the cached old MP3s.

4. Commit the regenerated MP3s in `v3/assets/tour/` together with the
   tourSteps/TourEngine changes.

5. Before deploying, bump the `?v=` cache-busters in `v3/index.html`
   (run /deploy-front).

## Failure behavior

Missing or blocked audio must never block the tour — steps fall back to timers.
That is a safety net for demos, not an excuse to ship missing MP3s.
